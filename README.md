
Neural Network Chatbot using GPT API

We use this model to create a chatbot which can interact with the user and provide responses using GPT models.

Libraries used are numpy, pandas, openai, gradio and time.

The GPT model is accessed using the OpenAI API.

The steps used here are:

1. Installing the required libraries
2. Adding the OpenAI API key
3. Creating the ChatBot class
4. Specifying the model and system prompt
5. Creating a conversation history to remember the messages
6. Sending the user message to the GPT model
7. Getting the response from the model
8. Creating a text based chat loop
9. Creating a chat interface using Gradio
10. Running the chatbot and getting the final response
